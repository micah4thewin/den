# Bundled faces

The interface faces (Gilroy, Avenir Next LT Pro) are licensed separately and
were already here. The three handwriting faces below are under the SIL Open
Font License 1.1, which permits bundling them in an application as long as
they are not sold on their own and the reserved names are kept.

| Face | Designer | Licence |
| --- | --- | --- |
| Caveat | Pablo Impallari | SIL OFL 1.1 |
| Architects Daughter | Kimberly Geswein | SIL OFL 1.1 |
| Patrick Hand | Patrick Wagesreiter | SIL OFL 1.1 |

Each is the `latin` and `latin-ext` subset only, as served by Google Fonts.
The whiteboard writes Latin text, and the Cyrillic, Greek and Vietnamese
subsets would more than double the bytes for glyphs no label reaches. A
label typed in a script none of these cover falls through to the generic
family at the end of the stack, which is the same thing that happened before
any of them were here.

The full licence text is at <https://openfontlicense.org>. The upstream
sources are <https://fonts.google.com/specimen/Caveat>,
<https://fonts.google.com/specimen/Architects+Daughter> and
<https://fonts.google.com/specimen/Patrick+Hand>.
